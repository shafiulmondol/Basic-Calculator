# 🧮 Shafiul's GUI Calculator

A simple and interactive GUI calculator built using Python's Tkinter library. This application allows users to perform basic arithmetic operations through an intuitive graphical interface.

---

## 🚀 Features

- **Basic Operations**: Addition, Subtraction, Multiplication, and Division.
- **User-Friendly Interface**: Clean layout with responsive buttons.
- **Real-Time Display**: Immediate feedback of inputs and results.
- **Error Handling**: Displays 'Error' for invalid expressions.
